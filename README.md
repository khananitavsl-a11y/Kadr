## Что внутри
| Папка | Содержимое |
|---|---|
| `/docs` | Глава 1 «Идея» и глава 2 «Требования» (Word и PDF), список функциональных требований (CSV) |
| `/models` | Матрица влияния заинтересованных сторон, карта пути владельца бизнеса и другие схемы главы 2 |
| `/tests` | Матрица трассируемости (цель → требование → история → тесты) и тест-кейсы TC-001…079, TC-N01…N09 |
| `/prototype` | Прототип в Figma — появится на этапе 3 |
| `/team` | Журнал встреч и распределение ролей |
