# Kadr — маркетплейс креаторов Reels и TikTok для малого бизнеса Ташкента

Учебный проект по дисциплине «Программная инженерия» · Университет Пучон в Ташкенте · 3 курс, группа 7224B · преподаватель Ботиров С. Р.

Kadr помогает кафе, магазинам и салонам найти проверенного креатора, зафиксировать условия в брифе и заплатить только после приёмки роликов: деньги удерживает Payme или Click.

| [`tests/`](tests) | Тест-кейсы TC-001…079 и TC-N01…N09, матрица трассируемости (цель → требование → история → вариант → модуль → тесты) |

## Проект в цифрах
| Этап 2 | Этап 3 |
|---|---|
| 5 интервью, 37 ответов в анкетах | 2 модели BPMN, матрица RACI |
| 31 ФТ, 9 НФТ, 20 историй | 19 вариантов использования, 17 классов |
| 88 тест-кейсов | 17 таблиц БД, 8 модулей, 5 внешних интеграций |

## Как открыть модели
| Файл | Чем открыть |
|---|---|
| `*.bpmn` | [bpmn.io](https://demo.bpmn.io) или Camunda Modeler |
| `*.mmd` | [mermaid.live](https://mermaid.live) |
| `db_schema.dbml` | [dbdiagram.io](https://dbdiagram.io) |
| `*.html`, `*.svg` | любой браузер |
