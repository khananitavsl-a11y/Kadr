# Прототип Kadr

Основной сценарий владельца бизнеса: 7 связанных экранов, включая экран ошибки оплаты.

| Экран | Что показывает | Истории |
|---|---|---|
| S1 Каталог креаторов | фильтры, сортировка, карточки | US-05, US-06 |
| S2 Профиль креатора | портфолио, пакеты, отзыв | US-02…US-04, US-18 |
| S3 Бриф | обязательные поля, ошибка у пустого поля | US-07 |
| S4 Оплата | цена + 15% = итог, удержание, Payme/Click | US-10 |
| S5 Ошибка оплаты | «Деньги не списаны», повтор, смена способа | US-10 (критерий 4) |
| S6 Заказ | «Оплата удержана», шаги, чат | US-09, US-10, US-19 |
| S7 Приёмка | водяной знак, 72 ч, правки, спор | US-12…US-16 |
